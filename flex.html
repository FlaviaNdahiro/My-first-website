One axis at a time

Flexbox lays children out along a single direction — a row or a column — and then shares the leftover space between them. That makes it the right tool for nav bars, button rows and toolbars, and the wrong tool for a full page layout.

Live demo

Four boxes in a flex container. The second one is the one being experimented on: it has order: 2 so it moves to the end, and flex: 1 1 100px so it absorbs the spare room.

.flex-demo {
  display: flex;
  justify-content: space-evenly;  /* along the main axis  */
  align-items: center;            /* across the cross axis */
  flex-wrap: wrap;                /* allow a second line   */
  gap: 20px;
}

.flex-demo .child:nth-child(2) {
  order: 2;            /* jump to the end             */
  flex: 1 1 100px;     /* grow, shrink, 100px basis   */
  align-self: center;  /* override align-items for me */
}

Properties on the container

Property What it controls Common values
flex-direction Which way the main axis points row · column · row-reverse
justify-content Spacing along the main axis flex-start · center · space-between · space-evenly
align-items Position across the cross axis stretch · center · flex-end · baseline
flex-wrap Whether items may start a new line nowrap · wrap
align-content Spacing between wrapped lines stretch · center · space-between
gap Space between items Any length, e.g. 20px

Properties on the children

  • order — reorders visually without touching the HTML.
  • flex-grow — share of the spare space this item takes.
  • flex-shrink — how willingly it gives space back.
  • flex-basis — its size before growing or shrinking.
  • align-self — overrides align-items for one item.
Two fixes worth remembering. align-content only does something once the items wrap, and there is no such value as flex-center — the centring keyword is plain center.

Flex or grid?

Reach for flexbox when the content decides the sizes and you only care about one direction. Reach for grid when you are placing things into rows and columns — which is exactly what the shell around this text is doing.
