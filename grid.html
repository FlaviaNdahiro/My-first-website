The sketch that became this site

This dashboard started as a 5 × 5 grid exercise: a sidebar, a navbar, a main panel, a history list, a profile strip and a user information box. That sketch is no longer a demo — it is the layout you are reading this in.

The original 5 × 5 demo

Five equal columns, five equal rows, and six children that each span a different number of cells.

Side bar
Navbar with navigation
Main content with content cards
History as a list
Profile picture list
User information
.grid-demo {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
  grid-template-rows: repeat(5, 1fr);
  gap: 8px;
}

.div1 { grid-row: span 5 / span 5; }              /* full-height sidebar */
.div2 { grid-column: span 4 / span 4; }           /* navbar across the top */
.div3 { grid-column: span 3 / span 3;
        grid-row: span 3 / span 3;
        grid-column-start: 2; grid-row-start: 2; } /* main content */

From demo to real layout

Spans and line numbers work, but they are hard to read six months later. Named areas say the same thing in a shape you can see at a glance — so the shell of this site uses those instead. 

.app {
  display: grid;
  grid-template-columns: 240px 1fr 1fr 300px;
  grid-template-rows: auto 1fr auto auto;
  grid-template-areas:
    "side  nav   nav   nav"
    "side  main  main  hist"
    "side  prof  prof  user"
    "side  foot  foot  foot";
}

.sidebar { grid-area: side; }
.topbar  { grid-area: nav;  }
.main    { grid-area: main; }
Why auto 1fr auto auto? The navbar and the bottom panels only need the height of their content (auto), while 1fr lets the main panel take every remaining pixel — so short pages still fill the screen.

Making it responsive

Named areas make a breakpoint almost trivial: redraw the picture with fewer columns and every panel follows.

Above 1180px

Four columns. Sidebar, main content and the history panel all sit side by side, with the profile and user boxes underneath.

861px – 1180px

Three columns. The history panel drops below the main content and its list becomes two columns so the height stays sensible.

Up to 860px

One column. The sidebar turns into a horizontally scrollable row of pills at the top, and every panel stacks in reading order. 

@media (max-width: 860px) {
  .app {
    grid-template-columns: minmax(0, 1fr);
    grid-template-areas:
      "nav" "side" "main" "hist" "prof" "user" "foot";
  }
}
Try it: narrow this window and watch the panels above change places. The demo grid itself stacks into a single column below 560px, because five equal columns on a phone would be unreadable.

Useful grid vocabulary

Property What it does
grid-template-columns Defines the column tracks, e.g. repeat(5, 1fr)
grid-template-areas Draws the layout as a picture of named regions
grid-area Assigns an element to one of those names
span n Makes an item cover n tracks
minmax() A track that never shrinks or grows past given bounds
auto-fit + minmax() Cards that rewrap themselves with no media query at all
